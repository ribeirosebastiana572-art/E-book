# Como os Ricos Enriquecem

Site comercial e versão web do e-book **Como os Ricos Enriquecem**.

## Arquivos
- index.html — landing page, apresentação, amostra e oferta.
- styles.css — identidade visual responsiva.
- app.js — comportamento do menu mobile.

## Kiwify
O botão de compra está preparado com um endereço de placeholder. Depois de criar o produto na Kiwify, substitua o endereço em index.html pelo checkout real.

## Projeto
O GitHub é a fonte oficial do código. O Lovable será usado apenas para visualização/preview.

O conteúdo é educacional e não promete enriquecimento ou retorno financeiro garantido.
