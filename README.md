# Como os Ricos Enriquecem

Edição digital do e-book **Como os Ricos Enriquecem**.

## Estrutura
- `index.html` — interface do leitor.
- `styles.css` — visual responsivo do e-book.
- `app.js` — 10 módulos, 35 aulas, navegação, progresso e exercícios.
- `ebook-data.js` — dados reservados para a versão digital do material.

## Leitura
O conteúdo é aberto no site, sem login, pagamento ou bloqueio. O progresso e as respostas dos exercícios são armazenados localmente no navegador do leitor.

## Projeto
O GitHub é a fonte oficial do código. O Lovable é usado somente para visualização/preview.
